# Rook 0.21.6

- `Retry-After` accepts decimal delay-seconds or an HTTP date through the shared
  provider/catalog parser. Dates use the local receipt clock and retain the
  existing 120-second ceiling, including fractional boundary checks. Past dates
  add no delay beyond ordinary backoff. Invalid, overflowing or more distant
  advice leaves ordinary backoff in force. Numeric values require ASCII digits.
- Completion checks capture a frozen current-stage history range before reading
  evidence. Acquisition scans at most 1024 events, retains at most 128 visible
  entries and keeps at most 2000 text bytes per entry. Session metadata is admitted
  at 64 KiB and each event metadata record at 16 KiB before decoding. Verified
  range reads check the whole payload, so both raw and stored payload sizes must
  fit 2 MiB before text or browser-caption reads.
- Bookkeeping is filtered before resolving bodies. Large attachment frames are
  omitted before decoding; unused UI companions are not loaded. Browser image
  attribution keeps its existing caption/object binding without decoding pixels.
  Read failures retain explicit issues and anchored placeholders instead of
  silently removing the excerpt.
- Coverage records report omissions and shortened payloads. The renderer can
  shorten the excerpt further. The saved journal, original goal and constraints,
  and completion-verdict rules are preserved. Recovery starts at the stage floor
  with `session_recall`, because its continuation cursors move forwards; starting
  at the newest omitted event would strand earlier evidence. Missing excerpt
  content does not establish that an action never happened.

`httpdate` 1.0.3 becomes a direct dependency but was already transitively locked.
External package/version/checksum records are unchanged. No new configuration
key, store format or MSRV change. The implementation independently adapts pinned
Hermes retry parsing and Pi committed-range ideas; reference pointers are unchanged
and no upstream implementation is copied. See [reference credits](../../references/PORTED.md).

frontend builds and the complete workspace test suite on Linux. The corrected

history10 steps on Linux, Windows and macOS. Scripted checks establish
