# Rook 0.21.19

The native Google provider now sends tool JSON Schema in `parametersJsonSchema` for ordinary and streaming requests. This preserves declarations containing definitions, references and composition keywords, including MCP tool schemas.

For Gemini compatibility, string and number `const` values become singleton `enum` constraints only in schema positions without an explicit enum. Literal values in defaults, examples, enum/const data and unknown annotations remain unchanged; the original logical request is preserved.

Google still determines which JSON Schema features it accepts. This change does not promise compatibility with older third-party Google-shaped endpoints or establish live model acceptance, quality or speed.

Pinned Pi references and independent implementation details are recorded in `references/PORTED.md`.

See [Gemini tool schemas](../gemini-tool-schemas.md).
No dependency or minimum Rust version change is included.
