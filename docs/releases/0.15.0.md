# Rook 0.15.0

Rook 0.15.0 adds safer skill updates, reusable prompt presets, richer saved diff inspection and an optional MCP Apps host.

- Skill updates retain their recorded source even when catalogs are reordered or a project skill masks the personal installation. Origin migration is explicit; replacements are prepared before publication.
- Agents and operators can page through bundled skill resources using a scoped content receipt, without granting access to the whole agent home directory.
- Readable reasoning is replayed only to the producing model; ordinary answers and tool history remain available after a model switch.
- Compaction budgets the actual request and output against the selected summarizer's context window.
- Prompt/model/effort presets work through CLI, API, the browser and the TUI's F8 picker. Loading preserves drafts and never submits a request or broadens permissions.
- Saved review diffs gain file navigation and responsive unified/split layouts. Binary changes retain original hashes and explicit omission notices.
- The conversation browser adds console diagnostics, failed-request observations and viewport controls with bounded, redacted results.
- MCP Apps are opt-in with `[mcp_connections] apps_enabled = true`. Self-contained apps run in opaque sandboxed frames; tool calls require explicit one-shot consent. Declining or ignoring a request never authorizes a call.
- All ten reference pointers were advanced and the adoption ledger records the source snapshots and implementation limits.

Validation: the full local `cargo xtask ci`, browser module tests, actual Chrome/Chromium probes and native PTY scenarios passed. No persisted store-format or Rust toolchain requirement change.

See [the adoption guide](../reference-followup-adoption.md) for commands, opt-in settings and supported scope.
