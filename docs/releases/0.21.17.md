# Rook 0.21.17

Background command output now preserves UTF-8 characters split across pipe
reads. Standard output and standard error keep independent decoders; incomplete
suffixes are retained until the next read and flushed on EOF, read error or
cancellation. Raw byte activity is still counted immediately. Existing malformed
byte and Windows legacy-encoding fallback behavior remains in place. The owned
CLI and daemon fixture covers live partial reads and complete multilingual
output; see [background work](../background-work.md).

Long words in TUI gutter/help text now wrap without repeatedly scanning and
copying the remaining suffix. The existing whitespace, paragraph and
Unicode-scalar wrapping behavior is preserved, including the one-column minimum.
This does not add terminal-cell-aware layout. See [the wrapper audit and measured
function-level fixture](../tui-wrapping.md); those measurements do not establish
whole-TUI latency or agent task speed.

Version-output capture retries interrupted pipe reads under its original
deadline and combined byte limit. Interruptions no longer become premature read
failures. Probe failures can emit bounded error-kind diagnostics under the
existing debug logging controls; captured version output is not logged. See
[version capture](../version-probe-capture.md). The defensive retry has injected
regression coverage; it does not establish the cause of an earlier macOS failure.

Git-backed skill catalogs support nested Windows home paths. Catalog Git
commands enable `core.longpaths` per command. When the cache's `.git/config`
path reaches 240 UTF-16 units, Git works in private temporary storage and a
prepared cache is published on the destination filesystem. Failed refreshes
preserve the previous cache, and an unexpected destination is refused. Warm
lookup still reuses the cache without HTTP. No global Git setting is changed.
See [source identity and path behavior](../catalog-source-identity.md).

Deep-cache copying keeps the existing limits of 2,000 entries, 64 MiB total and
8 MiB per file. Those limits do not bound the Git download or the whole
operation; Git's private temporary path must itself fit its startup limits.
Rollback failures retain the previous files and report their recovery path.

The streaming decoder and wrapper were implemented independently after auditing
the pinned Pi references credited in `references/PORTED.md`. The Windows cache
change follows reproduced Rook failures and Git for Windows documentation.
No dependency or minimum-Rust-version change is included.
