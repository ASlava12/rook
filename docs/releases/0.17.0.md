# Rook 0.17.0

Rook 0.17.0 delivers ten reference-inspired capabilities for reliable long-running
work, live MCP tools and inspecting related sessions.

- Model and reasoning effort commit as one durable selection. The next root turn
  uses an immutable pair; busy changes and exact retries cannot rewrite an
  admitted turn or a newer selection.
- Drain closes admission while keeping answers, private input and Stop reachable.
  An owned controller replaces the daemon only after quiescence; cancellation,
  timeout and failed handoff preserve explicit status.
- Compaction has an independent bounded phase deadline and cancellation. A late
  result cannot commit; source-retaining fallback preserves access to history.
- Main, compaction and errand requests can use independent ordered fallback
  chains. An explicit empty chain restricts a purpose to its primary.
- Delegated tasks can return schema-validated, redacted JSON with bounded receipts
  and saved child/event references. Child tools are not replayed into the parent.
- `rook session last-answer`, `/copy` and browser controls retrieve the saved
  answer from the selected branch. Clipboard refusal offers readable fallback.
- Explicit reasoning declarations report provenance and the actual API mapping,
  including unsupported values and provider clamps.
- Opt-in `refresh_tools = true` updates MCP catalogs at the next safe request
  boundary. Coalesced bounded refresh, source-bound pagination, retained call
  bindings, cooldown/status and Apps consent invalidation cover stdio and HTTP.
- Gemini malformed generations can recover within the shared retry budget before
  semantic delivery. Refused or invalid tool-call generations fail without
  dispatch or replay; reported failed-attempt usage remains accounted.
- `rook session background`, `/background`, API and browser correlate lazy
  parent/child navigation, actual executor observations and session-owned
  background-job metadata. Inspection preserves the current turn and draft.

The cycle also fixes a preset acknowledgement race that could overwrite newer
unsent text, and advances all ten reference pointers to reviewed snapshots.

Compatibility: live MCP refresh is off by default. Existing saved data remains
readable; model-selection receipts support the prior version. MCP discovery
continuations with nonzero offsets now require the returned `source` token and
matching name/query. Saved activity never proves a current executor. The
summarizer quality experiment remains inconclusive, so its 2048-token default
is unchanged. No additional credentials or services are required for these ports.
