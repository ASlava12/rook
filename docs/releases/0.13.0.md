# Rook 0.13.0

Релиз добавляет приватный ввод секретов, новые возможности MCP, чтение PDF и
прямую работу с удалёнными файлами по SSH. Все возможности используют общий
движок CLI, TUI, HTTP API и браузерного интерфейса.

## Новые возможности

- **Приватный запрос секрета.** Агент запрашивает имя и причину, пользователь
  вводит значение через отдельную форму или скрытый терминальный ввод.
  Модель и история получают только имя и статус. Значение сохраняется в
  хранилище секретов и доступно для разрешённой команды в том же ходе.
- **Отказ и отсутствие ответа.** Пропуск, таймаут, закрытие формы и отмена
  являются обычными исходами. Молчание не даёт разрешений и не подставляет
  согласие; повторные запросы того же секрета или MCP-диалога в том же ходе
  подавляются. EOF в терминале больше не выбирает утвердительный ответ.
- **MCP resources и templates.** Обнаружение и чтение ресурсов с ограничениями
  размера, постраничным выводом, привязкой продолжения к хэшу источника и
  поддержкой серверов без tools/list. Изображения используют общий механизм
  результатов, неподдерживаемые бинарные данные не попадают в контекст как base64.
- **MCP elicitation.** Формы и URL-запросы сервера привязаны к конкретному
  соединению, вызову и сессии. Есть проверка полей, просмотр перед отправкой,
  отказ и отмена. Ссылку открывает сам пользователь; открытие ссылки не считается
  завершением авторизации. Чужие и запоздавшие ответы отклоняются.
- **PDF для текстовых моделей.** `read_pdf` извлекает выбранные страницы,
  сохраняет их происхождение и поддерживает продолжение по проверенному
  источнику. Есть ограниченный рендеринг страницы и локальное OCR для сканов.
- **SSH-native workspace.** Опциональный `ssh_workspace` читает, ищет,
  перечисляет и изменяет файлы прямо на выбранном хосте и выполняет команды
  без локальной реплики. Сохраняются владельцы операций, контрольные суммы и
  чекпоинты для явного отката. CLI/API, команда `/environment` в TUI и
  браузерная панель позволяют просмотреть и откатить чекпоинт без модели.
- **Доменные правила сети.** Опциональная `sandbox.network_policy` допускает
  заданные host:port через ограниченный HTTP/CONNECT-брокер. На macOS Seatbelt
  закрывает прямой обход прокси через TCP/UDP. Решения сохраняются с ID вызова;
  неподдерживаемая среда отказывает в запуске вместо снятия ограничений.
- **Связанные диагностические данные.** Общая идентичность корневой и дочерних
  сессий, ACP/MCP и физических попыток генерации, включая повторы и переключения
  провайдера. Идентификаторы ответов провайдера входят в ограниченный локальный
  диагностический экспорт. Распространение trace-контекста наружу включается
  отдельно через `telemetry.propagate_trace` и по умолчанию выключено.

## Совместимость и границы

- Формат существующего хранилища сохранён. Минимальная версия Rust — 1.90.
- Текущий SSH-режим с репликой остаётся режимом по умолчанию.
  `execution_environment.native_workspace=true` требует Unix-клиент и доверенный
  SSH-профиль; удалённые команды требуют Linux, Python 3.9+ и pidfd.
  Команды выполняются с правами SSH-аккаунта. Откат ограничен выбранным корнем
  и настройками исключений; поздние внешние правки вызывают конфликт.
- Доменные ограничения пока поддерживают локальные foreground-команды на macOS
  с доступным Seatbelt. Фоновые команды, SSH/контейнеры, терминалы редактора,
  внешние ACP-исполнители, hooks и инструменты без ограниченного сетевого пути
  в этом режиме недоступны. Это ограничение команд, а не сетевой экран всего
  процесса Rook или системы. Подробнее: [доменные правила](../domain-network-policy.md).
- Для PDF нужны локальные Poppler (`pdfinfo`, `pdftotext`, `pdftoppm`);
  OCR дополнительно требует Tesseract и нужные языковые данные. Облачного
  распознавания и автоматического скачивания моделей нет.
- Проверка кэширования на развёрнутой Qwen не показала полезного улучшения.
  Новые cache/effort-параметры не включены; результаты и ограничения эксперимента
  сохранены в [отчёте](../research/prompt-cache-20261015.md).
- Обновлены указатели десяти репозиториев-референсов.

## Проверка

До подготовки версии прошёл полный локальный `cargo xtask ci`, а также
отдельные проверки последних изменений журналирования и браузерной панели.
Проверены реальные SSH-выполнение, разрыв связи, скрытие секретов и откат на
разрешённом Linux-хосте, доступ через доменный брокер к LAN и npm registry,
блокировка прямых TCP/UDP и `--noproxy`, а также собственность запросов,
продолжения, отказы и восстановление через CLI/демон/TUI.

Точная область и свидетельства проверок: [перенос функционала](../reference-functional-adoption.md).
