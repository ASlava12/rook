# Rook 0.21.15

Completed direct local foreground Cargo failures can append cited passages from
kept Rust error documentation. Each code is considered once per turn. Advice
works with shell undo off, including when the original capture or descendant
cleanup remains incomplete; the existing exit, capture and cleanup facts stay
visible. Advice never certifies a diagnosis, successful fix or goal progress.

`docs` accepts `local_only: true`. A miss returns before source clients or network
approval; combining it with `refresh` is rejected. Exact requested versions are
respected during neighboring-topic fallback. Ordinary fetching remains available,
and existing domain-policy tool restrictions remain in force.

Memory review tokens remain valid across elapsed time and reopening the store
when the reviewed inputs are unchanged. A change to the memory head still
requires a fresh review. Previously, generating a new creation timestamp during
application could invalidate an unchanged proposal at the next second.

Local reads admit at most 128 reference rows with one lookahead and eight nearby
sets. Each set admits 512 KiB of encoded and decoded data before payload copying
or decompression; an external read permits one refusal byte. Sets permit 32 pages,
128-byte topic/version fields, 2,048-byte URLs and 512-byte titles. Query text is
limited to 2,048 bytes; a local-only response to 16 KiB. Invalid, oversized or
unadmitted entries produce an incomplete-coverage notice. These are reader and
presentation limits, not a whole-process memory or elapsed-time guarantee.

Build notes recognize at most two plain `error[Edddd]:` codes in the first 256
lines of a visible-output prefix of at most 64 KiB. ANSI-colored and JSON
diagnostics, wrappers, background/editor/remote execution, timeouts and uncertain
execution receive no notes. At most sixteen codes are remembered per turn; a
miss is silent and notes share 6,000 bytes. The prefix follows secret masking and
excludes later receipts and hook text. Advice is appended after cycle/progress
comparison, with no implicit fetch, compiler invocation or extra model request.
