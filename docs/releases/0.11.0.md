# Rook 0.11.0

## Conversations and long-running work

- Restore live chat after reconnecting, including pending questions, tool results
  and editable queued messages. Retry acknowledgements keep their saved identity
  across disconnects and daemon restarts.
- Edit, reorder, withdraw and inspect queued messages. The next waiting message
  stays at the bottom of the TUI while the model is answering.
- Navigate conversation trees, branch from historical events, name/bookmark
  branches and review optional summaries with explicit source attribution.
- Configure prompt-editing keys, undo prompt edits and wrap long pasted input.
- Export bounded HTML conversation history and inspect saved tool results,
  measured dispatches, retained images and file-change previews.

## Models, accounting and reliability

- Opt into separate planning/implementation models while preserving compatible
  images and scoped provider state across continuation, compaction and reopening.
- Inspect request sources and tool catalogs, durable physical model attempts,
  auxiliary usage and frozen delegated cost coverage. Missing coverage remains
  explicit rather than being reported as a zero cost.
- Honor Responses stream retry advice before delivered content, interrupt runaway
  narrative repetition and stop repeated tool cycles without verified progress.
- Batch browser Markdown rendering with bounded buffering and view ownership.
- Explicitly refresh a bounded public model-price catalog and review suggested
  rates before applying them. Custom endpoints and old receipts retain their
  existing pricing semantics.

## Delegation and integrations

- Recover a missing delegated worktree from its reviewed registered Git index
  while preserving existing/recreated files and source attribution.
- Negotiate ACP child-session, compaction and error previews; old clients keep
  their existing protocol behavior.
- Deliver bounded live extension reports and streaming input forms across chat
  frontends, with source-owned saved reports and recovered browser drafts.
- Coalesce intermediate child progress within configured limits while preserving
  exact durable calls, results and execution receipts.
- Prepare daemon projects without retaining engine locks during disk discovery;
  shared children reuse equipment and isolated worktrees retain their own roots.
- Verify accepted corrections, unanswered questions and rejected approaches across
  long-task compaction and store reopening.

## Compatibility and installation

No store-format migration is required. Existing postcard records and stable wire
enums remain compatible; new protocol previews are negotiated. Phase routing,
public price refresh and branch-summary carry are optional. Rust MSRV remains
1.90. Real-model comparison and terminal image/scrollback investigations are
documented as evidence; they do not enable automatic model routing or add a new
terminal graphics protocol.

Release archives include `rook`, `rookd`, built-in skills and SHA-256 checksums
for Windows x64, Linux x64/ARM64 (musl), and macOS Intel/Apple Silicon. FreeBSD
remains supported from source. Use `rook update --check` to inspect the release
or `rook update` to install it.
